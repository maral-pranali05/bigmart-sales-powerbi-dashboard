# 🛒 Store Sales Analysis Dashboard

## 📌 Project Overview

The **Store Sales Analysis Dashboard** is an interactive Power BI dashboard designed to analyze store performance, product sales, outlet performance, and customer purchasing patterns. The dashboard provides meaningful business insights that help organizations make data-driven decisions.

---

## 🎯 Project Objectives

- Analyze overall sales performance.
- Identify high-performing products and outlet types.
- Compare sales across outlet locations and sizes.
- Analyze item visibility and customer preferences.
- Generate business insights through data storytelling.

---

## 🛠️ Tools & Technologies

- **Power BI**
- **Microsoft Excel / CSV**
- **Power Query**
- **DAX**

---

## 📂 Dataset

**Dataset:** Store Sales Dataset (CSV)

The dataset includes information about:
- Item Identifier
- Item Type
- Item MRP
- Item Visibility
- Item Fat Content
- Outlet Identifier
- Outlet Type
- Outlet Size
- Outlet Location Type
- Outlet Establishment Year
- Sales

## 📈 Key Business Insights

- Total Sales reached **661.98K**.
- Medium and Large outlets contribute the highest sales.
- High item visibility positively impacts sales performance.
- Regular fat-content products generate more sales.
- Some product categories outperform others consistently.
- Outlet performance varies across different outlet types and locations.
- Sales opportunities exist in lower-performing outlet segments.

---

## 💡 Business Recommendations

- Increase inventory for high-selling products.
- Improve marketing for low-performing categories.
- Focus on expanding successful outlet types.
- Improve product visibility through better placement.
- Optimize stock distribution across outlet locations.

---

## 📌 Project Outcome

This dashboard helps businesses monitor sales performance, evaluate outlet efficiency, understand customer preferences, and make informed business decisions using interactive visualizations.
